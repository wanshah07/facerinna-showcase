Sign in

Only addresses listed in the Admins tab of the booth sheet can sign in. Enter yours and a link will be mailed to you. No password.

Check your inbox. If that address is an admin, a sign-in link is on its way. It works once, for 20 minutes.

Nothing arrived? Check spam, or the address is not in the Admins tab.

What this does

Locked and Hidden draw a screen over the booth page; they do not take the file off the server, so treat them as a closed door, not a safe. The reports vault is gated by its own script and is not affected.

Changes reach the page on its next load. A phone that is offline keeps showing what it last saw.

Games, the events page and the vault are not covered by the lock; only the booth home page is.

Adding or removing an admin

Open the booth Google Sheet, tab Admins. One row per person: email, active (yes or no), name. Set active to no and every session that address holds stops working on its next call. That is the only place this list is edited, on purpose: a page that could add admins to itself would be one stolen session away from adding a stranger.
